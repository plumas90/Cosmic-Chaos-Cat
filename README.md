# Cosmic Chaos Cat

고양이 카드를 수집하고 성장시키며 다양한 조합을 만들어 나가는 캐주얼 수집형 게임입니다. 뽑기를 통해 새로운 카드를 획득하고, 상점과 업그레이드 기능을 활용해 게임을 진행할 수 있습니다.

## 게임 플레이

[웹에서 Cosmic Chaos Cat 플레이하기](https://plumas90.github.io/Cosmic-Chaos-Cat/)

## 테스트 방법

중앙 뽑기 버튼 옆에 있는 **올 컬렉션** 버튼과 **재화** 버튼을 사용하면 카드 수집 및 구매 기능을 빠르게 테스트할 수 있습니다.

테스트 데이터를 초기화하려면 **메인 메뉴로 이동한 뒤 게임을 새로 시작**하세요. 초기 상태에서 다시 테스트할 수 있습니다.
